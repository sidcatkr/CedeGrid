# Data Model: Everyday CLI for a Single User and Host

## Run
| Field | Type | Rules |
|---|---|---|
| `run_id` | string | Generated by the agent; unique per agent state. |
| `owner_uid` | integer | The agent's user; commands from other users are refused. |
| `launch_path` | `run` \| `sdk` \| `cluster` | Same supervisor path for all (FR-003). |
| `argv`, `cwd` | strings | From flags, the per-job entry or `--from-json`. |
| `env_names` | list of strings | Names passed at launch; values are never stored (FR-009). |
| `control_level` | `full` \| `tracked` | From detection at launch (FR-040). |
| `control_reason` | string | One sentence, e.g. why the run is Tracked. |
| `modes` | map kind → mode | Effective modes, capped by the node cap. |
| `granted_cores` | list of CPU ids | Tracked: the affinity mask; Full: the cgroup's CPU limit. |
| `state` | `starting` \| `running` \| `draining` \| `stopped` \| `failed` | See transitions. |
| `step`, `step_reason` | 001 yield step and reason code | Current step on each resource. |
| `flags` | set | `starved` (with since), `below_fair_share` (with reason), `bottleneck` (with causes), `possibly_misdirected` (with the thread IDs, FR-043). |
| `log` | path | Rotating log directory (R10). |

**Transitions**: `starting → running → draining → stopped`. Also `running → stopped` (normal
exit), `starting → failed` (refused, for example `--require-containment` at Tracked), and
`draining → stopped` (drain done or forced). A forced stop goes from `draining` straight to
`stopped`, through verified processes only.

## Verified member (Tracked)
| Field | Type | Rules |
|---|---|---|
| `pidfd` | descriptor | Opened before any check; the only handle used to act (Principle I). |
| `pid`, `start_time` | integers | For display and the tree walk; never used to act. |
| `parent_chain_ok` | bool | The chain reaches the run's leader. |
| `ids_match` | bool | Real, effective, saved and filesystem user and group IDs equal the run's. |
| `alive_after_check` | bool | Confirmed through the pidfd after the reads. |
| `own_affinity_changed` | bool | Reported when the process set a mask CedeGrid did not set. |
| `misdirected_tids` | set of thread IDs | Threads whose affinity change may have been misdirected: the post-check failed. Never touched again; shown in `ps --json` and the log (FR-043). |
| `thread_identity` | `thread_pidfd` \| `proc_start_time` | How thread identity is fixed around each call: a thread pidfd on Linux 6.9 and later, else the task entry with its start time. |

A member joins only when all three checks hold. It leaves when it exits, when its IDs change,
or when its chain cannot be confirmed.

## Local agent
| Field | Type | Rules |
|---|---|---|
| `socket_path` | path | Runtime directory, or the home state directory; 0700 directory. |
| `mode` | `local` \| `cluster` | A cluster agent also serves the socket and never idles out. |
| `idle_exit_s` | integer | Default 600; local mode only. |
| `lock` | namespace lifetime lock | At most one agent per user per host. |

## Per-job entry (`cedegrid.toml`)
| Field | Type | Rules |
|---|---|---|
| key | `[run."<script path>"]` | Path relative to the file's directory; for `--` commands, the first argument after the interpreter (FR-022). |
| `profile` | optional string | Selected with `-p NAME`. |
| task fields | as the task schema | Only modes, GPU selection, requests, class, retries, `threads` and env names (FR-026). |
| `env` | list of names | Values only with `--save-env`, stored as `env_values`. |

Floors, the node cap and margins cannot appear in a per-job entry; validation refuses them.

## Effective value
| Field | Type | Rules |
|---|---|---|
| `field` | schema field | Every field shown by `--explain`. |
| `value` | JSON | The value the run uses. |
| `source` | `flag` \| `per_job` (with file and key) \| `global_setup` \| `default` \| `threads_auto` | Precedence in that order (FR-025); `threads_auto` only for the thread variables. |

## Contention evidence
| Field | Type | Rules |
|---|---|---|
| `uid` | integer | Other users; the owner keeps the owner principal. |
| `run_delay_ms` | integer per interval | Summed per-thread deltas; exited threads dropped. |
| `cpu_millicores` | integer | From `/proc/<pid>/stat`, for the probe's growth check. |
| `coverage` | `per_user` \| `host_level` | `host_level` when process details are hidden. |
| `scan` | threads visited, threads total | Bounded by `evidence.max_threads_per_interval`. |
| `allowed_cpus` | list of CPU ids | Union of the principal's processes' `Cpus_allowed_list`, read-only (FR-056). |
| `pinned_overlap` | list of CPU ids, or unknown | `allowed_cpus` ∩ own work's granted cores; unknown when `allowed_cpus` is. While the principal's wait stays at the contending level for the probe's response window and the overlap is non-empty or unknown, the probe does not record it as satisfied. |

## Control level detection
| Field | Type | Rules |
|---|---|---|
| `level` | `full` \| `tracked` | Full only when every Full check passes; any error gives Tracked. |
| `user_manager` | bool | `systemctl --user` reachable. |
| `delegated` | controllers | `cpu` and `memory` must be present. |
| `contenders_share_cgroup` | `yes` \| `no` \| `unknown` | Decides whether SCHED_IDLE and autogroup apply. |
| `forced_tracked` | bool | Test-only switch. |
